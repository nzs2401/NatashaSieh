# GPU-Accelerated Side-Scan Sonar Simulation — OceanSim 2.0

**GPU-accelerated side-scan sonar simulator extending the open-source OceanSim framework, modeling real-world acoustic physics — co-author, IEEE OCEANS 2026.**

## Context
UMich Field Robotics Group, Prof. Katherine Skinner, May 2025–April 2026. Extends the open-source [OceanSim](https://github.com/umfieldrobotics/OceanSim) underwater robotics simulation framework for OceanSim 2.0 — co-author, "Towards Scaling Marine Perception with Synthetic Data" (IEEE OCEANS 2026).

## What I Built
- GPU-accelerated side-scan sonar simulator in NVIDIA Isaac Sim, using custom CUDA kernels for acoustic ray-tracing and beam pattern simulation
- Built on PhysX and Warp to model real-world underwater acoustic physics
- Validated against real-world shipwreck sonar imagery, reducing the need for costly at-sea testing
